# Data

## `raw/healthcare-dataset-stroke-data.csv`
Kaggle "Stroke Prediction Dataset" — 5,110 rows, 12 columns.

| column | description |
|--------|-------------|
| id | patient identifier (dropped) |
| gender | Male / Female / Other |
| age | age in years |
| hypertension | 0 / 1 |
| heart_disease | 0 / 1 |
| ever_married | Yes / No |
| work_type | children / Govt_job / Never_worked / Private / Self-employed |
| Residence_type | Rural / Urban (dropped) |
| avg_glucose_level | average glucose level (mg/dL) |
| bmi | body mass index (has missing values → imputed with the mean) |
| smoking_status | formerly smoked / never smoked / smokes / Unknown |
| stroke | **target** (0 / 1) — highly imbalanced (~4.9% positive) |
